# 结案数据报告 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：商单对接管家 的使用者"]
  T["触发层：结案数据报告"]
  X["执行层：3 个步骤"]
  O["产出层：续约建议"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 有商单能力的腰部以上创作者（受众较窄，据 R2 调研痛点 #8）；员工定位：帮中腰部博主建立报价体系、不再贱卖流量的商务助理 |
| 触发层 | 关键词 / 显式点名「结案数据报告」；触发方式：事件（结案） |
| 执行层 | 投放数据 → 结案报告 → 续约建议 |
| 产出层 | 续约建议 |
